# CountWords

Программа на GNU Pascal для подсчёта слов в текстовом файле.

## v1

Программа:
- читает текстовый файл за один проход;
- считает словами последовательности букв русского и латинского алфавитов;
- поддерживает слова с дефисом, если дефис находится между буквами;
- не учитывает регистр;
- сохраняет статистику в файл `Statistics.txt`;
- выводит слова в алфавитном порядке.

## Структура

- `v1/CountWords.pas` — основная программа.
- `v1/WordStats.pas` — модуль со структурами данных и процедурами.
- `v1/TEXT.txt` — тестовый входной файл.
- `v1/expected_statistics.txt` — ожидаемый результат.

## Примечание

Для корректной обработки кириллицы входной файл должен быть сохранён в кодировке, совместимой с используемой средой GNU Pascal.
