# CountWords

Программа на GNU Pascal для подсчёта слов в текстовом файле.

## v1

Программа:

- читает текстовый файл за один проход;
- считает словами последовательности букв русского и латинского алфавитов;
- поддерживает слова с дефисом, если дефис находится между буквами;
- не учитывает регистр;
- сохраняет статистику в файл `Statistics.txt`;
- выводит слова в алфавитном порядке.

## v2

Во второй версии программа доработана для обработки файлов большой длины.

Программа:

- читает входной файл последовательно, слово за словом;
- не загружает исходный текст целиком в память;
- хранит промежуточную статистику в AVL-дереве;
- при достижении заданного количества узлов сбрасывает дерево во временный бинарный файл;
- после чтения входного файла собирает итоговую статистику из временного файла;
- выводит итоговую статистику в файл `Statistics.txt`.

## Структура

- `v1/CountWords.pas` — основная программа первой версии.
- `v1/WordStats.pas` — модуль первой версии со структурами данных и процедурами.
- `v1/TEXT.txt` — тестовый входной файл для первой версии.
- `v1/expected_statistics.txt` — ожидаемый результат для первой версии.
- `v2/CountWords_v2.pas` — основная программа второй версии.
- `v2/WordUtils.pas` — модуль для работы со словами.
- `v2/StatsTree.pas` — модуль для хранения статистики, AVL-дерева и временного бинарного файла.
- `v2/TEXT.txt` — тестовый входной файл для второй версии.
- `v2/expected_statistics.txt` — ожидаемый результат для второй версии.

## Примечание

Для корректной обработки кириллицы входной файл должен быть сохранён в кодировке, совместимой с используемой средой GNU Pascal.
